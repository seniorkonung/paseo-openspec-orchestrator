### Language preferences

Use Russian by default for all text in this repository and for communication with the user.

IMPORTANT: Russian is mandatory for:

- Communication with the user.
- Human-facing documents: PRDs, task documents, specifications, research notes, project guides, journals, and public text, even when agents also read them.
- Code comments.
- Test names and test descriptions.

Use English only for text intended exclusively for agents, including agent instructions and skills. Agents handle English more reliably, and it usually uses fewer tokens.

Continue existing English-language documents in English for consistency.
