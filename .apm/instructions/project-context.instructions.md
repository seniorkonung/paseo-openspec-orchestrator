### Project context

At the start of every new session, before planning or editing repository files,
read the root `README.md` in full. Use it to understand the project's purpose,
architecture, terminology, and current implementation status. Verify detailed
behavior against the source code and tests. When a change materially affects the
project's scope or architecture, update the README in the same change.
